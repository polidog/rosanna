# `.psx` のエディタ対応

Rosanna の PSX のための構文ハイライトです。構文の定義は
[`docs/spec/03-compiler.md`](../docs/spec/03-compiler.md) の §2 にあります。

| エディタ | 場所 |
|---|---|
| VS Code | [`vscode/`](vscode/README.md) |
| Vim、Neovim | [`nvim/`](nvim/README.md) |

色分けするもの:

- 組み込みのタグ (`<div>`) とコンポーネント (`<Counter />`)
- Fragment (`<>...</>`)
- 属性の名前、文字列の値、`{式}` の値
- テキストと文字列の属性値の中のエンティティ (`&amp;`)
- `{}` の中の PHP。その中にさらに書いたタグも色分けします
- `style` と `script` の中身。`{}` を PHP の式として扱いません

型の検査、補完、定義へのジャンプは扱いません。確かめるときは [`sample.psx`](sample.psx) を開いてください。

## 制約

`<` が比較かタグかを字面で推測します。コンパイラのように式の開始の位置を調べないので、`$a <b>` のように書くとタグとして
色が付きます。`$a < $b` のように `<` の後に空白を入れれば比較のままです。
